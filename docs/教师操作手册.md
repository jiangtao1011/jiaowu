# 教师操作手册

> 适用角色：教师（及教研组长、备课组长、年级组长中属于「本人」的部分）。
> 系统分「电脑端」和「手机端」，教师日常操作（申报、代课调课、看课时）主要在手机端完成。
> 本文以步骤为主，每一步即一个独立动作，便于后续生成操作流程图。

---

## 一、登录

### 方式 A：账号密码登录
1. 打开系统网址，进入登录页。
2. 输入「用户名」「密码」。
3. 点「登录」。
4. 登录成功后自动进入首页（手机端进「首页」，电脑端进「工作台」）。

### 方式 B：扫码登录
1. 让已登录的同事在电脑端点「扫码登录」生成二维码。
2. 用手机浏览器打开网址，进入登录页（带 `code` 参数会自动登录）。
3. 或用手机扫码后自动跳转登录。
4. 登录后即进入手机端首页。

> 注：二维码 3 分钟内有效，一次性使用。

---

## 二、首页（手机端）

登录后默认进入首页，主要信息：

1. **今日课程**：查看当天各节次的科目、班级、时段。
2. **本周课表**：按周一到周五横排预览，点「查看全部」进入完整课表。
3. **任教班级**：查看所教班级、学科、每周节数。
4. **我的申报**：查看最近申报记录及审核状态。

---

## 三、自主申报（核心）

底部点「申报」，进入申报首页，可申报四类课务。

> 通用规则：提交后先由**年级组长一审**，再由**课程中心终审**，终审通过才计酬。
> 状态含义：待年级组长审核 → 待课程中心终审 → 已通过 / 已驳回 / 已撤回。

### 3.1 申报答疑
1. 点「申报答疑」。
2. 选择「年级」（答疑针对年级，不针对班）。
3. 选择「日期」。
4. 用 +/− 调「节数」。
5. （选填）填「内容说明」。
6. 点「提交答疑申报」。

### 3.2 申报晚自习
1. 点「申报晚自习」。
2. 选择「班级」（针对你代课年级的具体班级）。
3. 选择「日期」。
4. 调「节数」。
5. （选填）填「内容说明」。
6. 点「提交晚自习申报」。

### 3.3 申报早自习
1. 点「申报早自习」。
2. 选择「年级」（针对年级，不针对班）。
3. 选择「日期」。
4. 调「课时数」。
5. （选填）填「内容说明」。
6. 点「提交早自习申报」。

### 3.4 申报私人定制课
1. 点「私人定制课」。
2. 选择「类型」（一对一 / 一对二 / 一对多）。
3. 选择「年级」。
4. 选择「学科」。
5. 选择「日期」。
6. 调「节数」。
7. （选填）填「内容说明」。
8. 点「提交私人定制课」。

### 3.5 查看 / 删除申报记录
1. 在申报首页下滑到「我的申报」。
2. 查看每条记录的状态（待审 / 待终审 / 已通过 / 已驳回）。
3. 状态为「待年级组长审核」或「待课程中心终审」时，点「删除」可撤回该条（终审通过后不可自行删除）。

---

## 四、代课 / 调课

底部「我的」→「代课调课」进入。

### 4.1 发起代课 / 调课申请
1. 进入「发起申请」标签。
2. 「选择我的课」下拉选一节课。
3. 选「类型」：代课 / 调课。
4. 选「目标教师」（代给谁 / 调给谁）。
5. 选「时长」：单日 / 日期区间 / 长期。
6. 选「开始日期」（区间时长还需选「结束日期」）。
7. （选填）填「原因说明」。
8. 点「提交申请」。
9. 提示「申请已提交，待教务主任审核」。

### 4.2 查看 / 撤回申请
1. 切到「我的申请」标签。
2. 查看每条申请的审核状态。
3. 状态为「待审核」时，点「撤回」可取消。

---

## 五、查看课时与课酬

底部点「课时」进入。

1. 默认显示「我的课时」。
2. 顶部选「统计月份」查看不同月份。
3. 查看三个数字：原始课时、折算课时、课酬（元）。
4. 点某类型（如常规、答疑、晚自习）可展开查看该类型的每节明细。
5. 切「标准/系数」标签，可查看学科系数、班额系数、按次计酬单价。

---

## 六、查看通知与回复

底部点「通知」进入。

### 6.1 查看通知
1. 点「全部」或某类型标签筛选。
2. 点某条通知查看全文（点开即标记已读）。

### 6.2 回复通知
1. 打开某条通知。
2. 在「回复」框填写内容。
3. 点「提交回复」。
4. 回复提交后待教务主任审核，可在「我的回复」查看状态。

---

## 七、查看教学业绩

底部「我的」→「我的业绩」进入。

1. 查看各学期的考核分（按备课组）。
2. 展开查看各考试得分、权重、各率。
3. 若显示「暂无已固化的业绩档案」，表示教务主任尚未固化，联系教务主任处理。

---

## 八、课程申报（分享链接填报）

当教务主任发布课程申报任务并分享链接时：

1. 点开链接（手机扫码或点链接）。
2. 按要求填写表单字段（文本框 / 下拉 / 数字 / 日期）。
3. 选「上课日期」。
4. 调「课时数」。
5. 点「提交申报」。
6. 提示「申报已提交，待教务主任审核」。

---

## 九、我的（个人信息）

底部点「我的」进入。

1. 查看姓名、角色、学科、电话、任教班级。
2. 通过「快捷入口」直达：我的课表、我的课时、我的业绩、代课调课。
3. 点「退出登录」退出。
