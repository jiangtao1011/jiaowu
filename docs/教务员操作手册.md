# 教务员操作手册

> 适用角色：**教务员**。
> 教务员属「执行层」，负责日常的**录入与维护**（班级、教师、课表、检查、成绩、通知等）。
> 审核、配置、建号、固化档案等由**教务主任 / 管理员**负责，本手册会逐处标明。
> 教务员日常操作主要在**电脑端**完成；本文以步骤为主，每一步即一个独立动作。

---

## 〇、先读：教务员的权限边界

| 模块 | 教务员可以做的操作 |
| --- | --- |
| 班级信息 | 新增、编辑、删除、批量导入 |
| 教师信息 | 新增、编辑、启用/停用、批量导入、维护任课关系 |
| 课表与调课 | 导入课表、拖拽调课、整节对调、代课/停课、撤回调整、补课课表管理、查看历史快照与版本对比 |
| 常规检查 | 提交检查、编辑/删除检查记录、查看统计、导出报表 |
| 统计中心 | 查看课酬统计、导出明细/财务表、按日「加课 / 代课 / 停课 / 恢复」 |
| 教学业绩 | 新建考试、录入/导入各率、上传成绩附件、查看考核汇总、查看教师档案（只读） |
| 通知 | 新建、编辑、发布、下线、删除、查看详情（已读名单与回复） |
| 教学计划上传 | 创建上传任务、上传/下载文件 |
| 工作台 | 查看总览、维护工作计划日历 |

| 操作 | 由谁负责（教务员**无权限**） |
| --- | --- |
| 账号管理（建号、改角色） | admin / 教务主任 |
| 数据库管理 | admin 独占 |
| 课务申报审核（课时申报终审、课程申报审核、代课/调课申请审核） | 教务主任；年级组长负责课时申报「一审」 |
| 通知回复审核 | 教务主任 |
| 课酬系数、统计字典、校历、生成上课记录 | 教务主任 |
| 常规检查类型/维度/配置 | 教务主任 |
| 考核配置、固化业绩档案 | 教务主任 |

> 注：教务员登录后，侧边栏会看到「课务申报」入口，但进入后提示**无权限**——课时申报/课程申报的审核由教务主任与年级组长操作。教务员需要录入临时课时时，请用「统计中心 → 按日统计 → 加课」（见第七节）。

## 一、登录

1. 打开系统网址，进入登录页。
2. 输入「用户名」「密码」。
3. 点「登录」。
4. 登录成功后自动进入「工作台」。

> 教务员属管理层，用电脑访问时进入桌面端。若用手机访问，系统会自动跳转到手机端首页（手机端只提供教师自助功能，教务员的日常操作请在电脑端完成）。

---

## 二、工作台（首页）

登录后默认进入「工作台」，是教务管理的总览页，包含：

1. **概览计数**：班级数、教师数、已发布通知、检查记录、未来工作计划数。
2. **今日课务**：今天各节次的课程节数，以及今日校历、今日工作安排。
3. **待办审核**：答疑/课程申报/通知回复的待审数（教务员此处仅可查看，不能审核）。
4. **近期通知**：最近 6 条已发布通知。
5. **工作提醒**：未来 7 天提醒、逾期事项、上传任务截止。
6. **教务工作日历**（月视图）：点某一天可增删改查该日工作计划、标记完成。

> 工作计划日历人人可用，教务员可直接在这里维护「工作 / 会议 / 考试 / 检查 / 活动 / 其它」等日常安排。

## 三、班级信息

侧边栏「基础信息 → 班级信息」进入。

### 3.1 新增班级
1. 点「新增班级」。
2. 填写「班级名称」。
3. 选「类型」：行政班 / 分层 / 走班。
4. 填「人数」（走班可留空，系统自动按合班成员人数之和统计）。
5. 填「年级」（如 高一）。
6. 若为「分层」班，选「所属班级」（父班）；若为「走班」班，勾选「合班成员」。
7. 点「保存」。

### 3.2 编辑 / 删除班级
1. 在列表中找到目标班级。
2. 点「编辑」修改后保存；点「删除」移除。

> 删除班级前系统会检查引用：若该班已被课表、上课记录、申报、子分层或合班成员引用，会拒绝删除并提示原因。此时应改为「改名标记停用」而非强删。

### 3.3 批量导入班级
1. 点「批量导入」。
2. 点「下载导入模板」，按模板填好数据。
3. 选择文件，点「预览」，系统逐行校验。
4. 在预览里勾选要导入的行，点「确认导入」。

> 模板列：**班级名称 | 类型 | 人数 | 年级 | 所属班级 | 学科**。
> - 类型：行政班 / 分层 / 走班。
> - 分层班要在「所属班级」填父班名；走班要在「所属班级」用逗号分隔填合班班级名（如 `高一(1)班,高一(2)班`）。
> - 班级名称必须唯一。

---

## 四、教师信息

侧边栏「基础信息 → 教师信息」进入。

### 4.1 新增教师
1. 点「新增教师」。
2. 填写「姓名」（必填）、「电话」、「学科」。
3. 按需填写「课酬标准」（夏令营/冬令营/全员夏令营/全员冬令营/节假补课，单位：元/节）。
4. 点「保存」。

### 4.2 编辑 / 启用停用
1. 在列表找到目标教师。
2. 点「编辑」修改信息后保存。
3. 点「停用 / 启用」切换教师在职状态（停用后不参与新课表导入）。

### 4.3 维护任课关系
1. 在教师列表中展开该教师。
2. 可添加/移除该教师任教的班级（带学科与生效日期）。

### 4.4 批量导入教师
1. 点「批量导入」。
2. 点「下载导入模板」填好数据。
3. 选择文件，点「预览」，勾选要导入的行，点「确认导入」。

> 模板列：**姓名 | 电话 | 学科 | 夏令营 | 冬令营 | 全员夏令营 | 全员冬令营 | 节假补课**（后五列为课酬标准，可留空）。

## 五、课表与调课（核心）

侧边栏「日常事务 → 课表与调课」进入。页面顶部有三个视图：**课表视图 / 补课课表 / 课务调整**。

### 5.1 查看课表
1. 默认「课表视图」显示各班课表缩略图，点某个班可下钻查看单班完整课表。
2. 顶部可切换「最新 / 今天 / 快照日期」，还可点「对比」比较两个日期的课表差异（新增用色块标出）。
3. 点「打印课表」可打印某班课表。

> 「最新」= 当前生效的课表；短期调课/代课的结果在「今天」及之后可见。「快照日期」用于查看过去某一天的课表。

### 5.2 导入课表
1. 点「导入课表」。
2. 选文件（先用「下载导入模板」准备好数据）。
3. 选「导入方式」：
   - **追加（不改旧表）**：在现有课表上补充新课程。
   - **整体替换（全校）**：从生效日起全校启用新表。
   - **替换某年级**：从生效日起某年级启用新表。
   - **替换某时段**：从生效日起某时段（如夏令营）启用新表。
4. （选填）填「生效日期」；填了生效日期后会出现「结束日期」（留空=不设终点）。
5. 若导入「节假补课」课表，填「套号」（1/2/3 区分多套轮换）。
6. 点「预览」，系统逐行校验并显示将关闭的旧表条数。
7. 勾选要导入的行，点「确认导入」。

> 模板列：**班级 | 星期 | 节次 | 类型 | 时段 | 课程名称 | 教师**。
> - 班级、教师必须与「班级信息」「教师信息」里的名称完全一致。
> - 星期 1–7（1=周一）；类型：正课/早自习/晚自习/答疑；时段：常规/夏令营/冬令营/全员夏令营/全员冬令营/节假补课。
> - 系统会根据班级名称自动识别「行政班 / 分层 / 走班 / 走班分层」，无需额外填形式。
> - **追加 + 填生效日期** = 从生效日起，文件涉及的「班级×时段」整体换表；文件没覆盖到的旧课视为移除。

### 5.3 拖拽调课（两节课互换上课时间）
1. 在课表视图把一节课拖到另一节课上。
2. 弹出「调课确认」，核对两张课程卡（科目与教师一起对调）。
3. 选「生效时长」：长期 / 某一天 / 时间段（时间段需填起止日期）。
4. 点「确认调课」。

### 5.4 整节对调（某年级某星期两个节次整体互换）
1. 点「整节对调」。
2. 选「年级」「星期」，选两个不同的「节次」。
3. 点「确认对调」。

> 该操作会把该年级该星期这两个节次的**全部课**（含走班/分层）整体互换，长期生效。

### 5.5 代课 / 停课（按日调整）
1. 进入「统计中心 → 按日统计」。
2. 找到要调整的某一节课。
3. 点「代课」选代课教师后确认；点「停课」将该节课停掉。
4. 停课/代课的课可点「恢复」还原。

> 更完整的代课/调课申请由教师自己在手机端发起，教务主任审核。教务员在此按日处理临时变动。

### 5.6 课务调整记录
1. 切到「课务调整」视图，可查看全部代课/调课/停课记录。
2. 点「撤回」可撤销某条误操作（按时间倒序撤回；若其上还有未撤回的后续调整，会提示先撤回后续）。
3. 点「打印通知单」可打印某条调整的通知。

### 5.7 补课课表管理
1. 切到「补课课表」视图，按「套号」查看各套补课课表。
2. 点「删除本套」可整套删除（会同时清理已展开的上课记录）。

## 六、常规检查

侧边栏「日常事务 → 常规检查」进入。页签：**检查记录 / 提交检查 / 检查统计 / 检查类型**（「检查类型」为配置项，教务员无权限）。

### 6.1 提交检查
1. 切到「提交检查」。
2. 选「检查类型」（如 课堂常规、先听后上、备课本检查等）。
3. 若为「课表联动」类：选「日期 → 班级 → 节次」，系统自动带出教师与科目。
4. 若为「材料类」（备课本/听课本等）：直接选「被检查教师」。
5. 按维度打分（可点「全部满分/优秀/良好/及格」快捷设置，或用滑条/按钮逐项打分）。
6. （周期类）核对「第 N 周」标记。
7. 点「提交检查」。

### 6.2 查看 / 编辑 / 删除检查记录
1. 切到「检查记录」，可按日期、类型等筛选。
2. 点「查看」打开详情；详情里可点「编辑」「删除」。

### 6.3 检查统计
1. 切到「检查统计」。
2. 选日期范围，切「按教师 / 按备课组·教研组」。
3. 查看平均分、达标率、覆盖率；点「记录」下钻到某教师，点「成员」看组内明细。
4. 点「导出报表」下载 Excel。

---

## 七、统计中心

侧边栏「统计与资料 → 统计中心」进入。页签：**课酬统计 / 统计配置 / 其它统计**。

> 「统计配置」里的学科系数、班额系数、按次计酬类型、折算类型、分年级单价、校历、生成上课记录等，**新增/编辑/保存/删除由教务主任操作**；教务员点开「统计配置」可查看现有配置项，但保存或删除时会提示无权限。

### 7.1 查看课酬统计
1. 默认「课酬统计」，选口径：**按日统计 / 课表当前状态 / 课表按时间段推算**。
2. 按日统计：默认本月 1 号~今天，可选日期范围与时段筛选。
3. 查看每位教师的原始课时、折算课时、课酬（元），按类型（正课/早自习/晚自习/答疑/节假补课等）分列。
4. 点「导出明细 Excel」「导出财务汇总表」「导出财务审核包」下载报表；点「勾稽校验」核对数据一致性。

### 7.2 按日加课 / 代课 / 停课 / 恢复
1. 在「按日统计」模式展开「上课记录」区。
2. 点「加课」录入一节临时课（选班级、教师、学科、日期、节次、类型、时段）。
3. 对已有记录点「代课」选代课教师、点「停课」停掉该节、点「删」删除、点「恢复」还原。

> 校历（放假/停课/补课/调课）与「生成上课记录」由教务主任在统计配置中维护，教务员不可改；教务员在统计结果里能看到校历对计酬的影响。

## 八、教学业绩

侧边栏「统计与资料 → 教学业绩」进入。页签：**考试与成绩 / 考核汇总 / 教师档案 / 考核配置**。

> 教务员可：新建考试、录入/导入各率、上传成绩附件、查看考核汇总、查看教师档案（只读）。
> 「考核配置」与「固化本学期档案」属教务主任权限——教务员界面虽能看到入口，但保存配置 / 固化时会提示无权限。

### 8.1 新建考试
1. 切到「考试与成绩」。
2. 点「新建考试」，填考试名称、学期、考试类型（期末/期中/月考/学考/会考等）。
3. 点「创建考试」。

### 8.2 录入各率
1. 在考试列表点「录入各率」。
2. 按「备课组」逐行录入各率（如 A 率、B 率，具体率项由考核配置决定）。
3. 可点「下载模板」批量导入，或点「保存各率」保存。
4. 上传成绩文件作留档（附件）。

### 8.3 查看考核汇总
1. 切到「考核汇总」。
2. 选学期，点「查询」。
3. 查看各备课组/教师合成的考核分。

> 各率的「权重」与「考试类型权重」由教务主任在「考核配置」里设置；「固化本学期档案」也由教务主任操作（固化后教师才能在手机端看到自己的业绩）。

---

## 九、通知

侧边栏「统计与资料 → 通知」进入。

### 9.1 新建通知
1. 点「新建通知」。
2. 填「标题」、选「类型」（教学/考试/活动/其它等）。
3. 在正文用 Markdown 编写，可点工具栏插入图片（上传后嵌入正文）。
4. 可上传附件（最多 10 个）。
5. 点「保存」（保存为草稿）。

### 9.2 发布 / 下线
1. 在通知列表，草稿状态点「发布」，已发布状态点「下线」。
2. 发布后可点「复制链接」获取免登录分享链接，或下载二维码/分享图转发。

### 9.3 查看详情
1. 点「详情」，查看已读名单、赞数、回复列表（含待审回复）。

> 教师/访客的**回复审核**（通过/拒绝）由教务主任操作，教务员在详情页仅可查看回复内容。

### 9.4 编辑 / 删除
1. 点「编辑」修改标题/类型/正文后保存。
2. 点「删除」移除通知（会级联删除附件、已读、回复、点赞）。

---

## 十、教学计划上传

侧边栏「统计与资料 → 教学计划上传」进入。

### 10.1 创建上传任务
1. 点「新建上传任务」。
2. 填「标题」，选「目标角色」或指定「目标用户」，填「要求」「截止日期」「允许文件类型」等。
3. 点「创建任务」。

### 10.2 查看 / 上传 / 下载文件
1. 在任务列表点「查看/上传文件」。
2. 查看该任务下已上传的文件。
3. 点「上传」代传文件，或点「下载」取回文件。
