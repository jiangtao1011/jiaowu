# 课表日期筛选与版本对比设计

日期：2026-11-14
状态：已确认，待实现

## 背景

「课表与调课」的课表视图目前只显示「当前最新」课表，管理者无法核对过去的课表、无法预览未来换表后的样子，也无法直观看出一次换表到底改动了哪几节课。

后端 `GET /schedules` 早已支持 `as_of` 参数（`activeClause` 按 `[effective_from, effective_to)` 区间过滤），只是前端从未使用。因此本功能绝大部分是「把已有的日期快照能力暴露出来」，后端仅需新增一个版本时间轴聚合接口。

## 目标场景（一体）

1. **核对过去 / 预览未来**：选一个日期，看那天课表长什么样。
2. **对比换表差异**：选基准日期 A 与对比日期 B，单表展示 + 高亮差异。
3. **追踪版本时间线**：顶部时间轴列出换表节点，点节点跳转到那天。

## 交互模型

### 1. 单日期快照

- 日期选择器 + 快捷按钮「今天」「最新」。
- 「最新」= 现有无参查询（默认视图，也是当前使用习惯）。
- 选某天 = 带 `as_of` 查询那天生效的课表。

### 2. 顶部版本时间轴

- 工具条下方一条横向时间轴，列出本学期所有「换表节点」。
- 节点数据来自 `schedules` 表的 `effective_from` 聚合；记录数 ≥ 阈值（20 条）的日期视为一次「换表」（大节点），代课/调课的零星 1~2 条视为小节点（弱化）。
- 每个节点标生效日期，按年级拆分数量用于标注「仅高一」还是「全校」。
- 当前选中日期所在的区间段高亮；点任一点跳转到那天的快照。
- 默认单行折叠（约 36px 高），节点多时横向可滚动。

### 3. 差异对比（单表 + 高亮）

- 切到「对比」模式后多出一个「基准日期」选择器。
- 选 A（基准）和 B（对比），课表按 B 展示，相对 A 的变化高亮：
  - 教师/科目变了 → 黄色「变更」
  - B 有 A 无 → 绿色「新增」
  - A 有 B 无 → 灰色虚线「已删」占位（用 A 的信息展示）
- 与「年级/时段」现有过滤共存。

## 差异判定细则

- 最小单元是「课表记录」，业务键沿用槽位键：`class_id | day_of_week | period_no | period_type | term | makeup_set`。
- 同一键在 A、B 两天各自取最新版本，再比较：
  - 两边都有但教师/科目变了 → 变更
  - B 有 A 无 → 新增
  - A 有 B 无 → 已删
- 分层/走班本就是不同 `class_id`，天然不同键，不会误判。

## 数据流

1. 单日期快照：复用 `GET /schedules?as_of=日期`，前端透传；默认「最新」走无参查询。
2. 差异对比：前端并行拉两次 `GET /schedules?as_of=A` 与 `?as_of=B`，内存里按业务键 diff。数据量几百条，无性能问题。
3. 版本时间轴：新增 `GET /schedules/versions`，返回 `effective_from` 聚合（日期 + 记录数 + 按年级拆分数量）。

## UI 版式

工具条（课表视图顶部，从上到下）：

1. 现有筛选行（年级 / 时段）保持不变，右侧新增日期控件组：快捷按钮 + 日期选择器 + 「对比」切换。
2. 时间轴：筛选行下方、课表上方一条横带，从左到右按时间排节点，节点间连线。

## 与现有功能的共存

- **拖拽调课 / 详情弹窗的代课停课**：仅在「最新」视图可用。历史日期或对比模式只读，隐藏/禁用写入操作，提示「历史快照只读」。
- **打印课表**：打印当前所看日期对应的课表（标题带日期）。
- **补课课表 / 课务调整**子视图不受影响，仅「课表视图」接入日期能力。

## 边界情况

- 选到学期开始前的日期 → 空表，显示「该日期无生效课表」。
- 对比 A、B 同日 → 提示日期相同，不产生高亮。
- 对比 A > B → 允许，但明确标注方向，避免「新增/已删」反了。
- 移动端不接入，保持简单；桌面端窄窗口自然换行。

## 实现清单

1. 后端 `GET /schedules/versions` 聚合接口。
2. 前端工具条 + 时间轴 + `as_of` 透传。
3. 前端差异高亮与只读态。
