# 竞赛课收费/不收费改造设计

> 2026-11-24 · 教务管理 · 课程申报模块

## 背景

竞赛课（`pay_mode='固定折算'`、`period_type='竞赛'`，系数 2）目前只有一种形态：填报时填课时数，计酬 = 课时数 × 竞赛系数（折算，不计钱，供教学业绩考核）。

实际竞赛课分两种：
- **不收费**：不录入学生姓名，折算 = 课时数 × 竞赛系数（现状）。
- **收费**：需录入学生姓名（多个），课酬金额**由教务主任审核时人工输入**，不计折算课时。

## 已确认决策

1. **收费/不收费是填报级**：老师每次填报时选，不是建课时定死。
2. **收费课计酬 = 审核时人工输入金额**：教务主任审核时手动填写本次课酬金额。
3. **收费课不保留折算课时**：只计钱、不计业绩折算；不收费课仍走折算。

## 数据模型

| 表 | 新增列 | 说明 |
| --- | --- | --- |
| `application_tasks` | `chargeable INTEGER DEFAULT 0` | 本课程是否「支持收费」（建课时勾选，竞赛课勾上） |
| `applications` | `is_charge INTEGER DEFAULT 0` | 本次填报是否收费 |
| `applications` | `charge_amount REAL` | 收费金额（审核通过时人工输入） |
| `lesson_instances` | `manual_pay REAL` | 人工课酬金额，覆盖 computePay 的折算/单价计算 |

## 计酬口径

`computePay` 在**最优先**位置新增判断：

```
if (r.manual_pay > 0) return { weighted: 0, pay: r.manual_pay * count };
```

即「手工金额」优先于折算字典、按次字典、非规时段——收费竞赛课折算课时为 0、课酬 = 人工金额。

## 填报（CourseApply.jsx）

竞赛课（`chargeable` 且 `pay_mode='固定折算'`）表单顶部显示「收费 / 不收费」开关：

- **不收费**：显示「课时数」stepper（现状），提交 `is_charge=0`。
- **收费**：显示「学生名单」多行输入框（每行一个姓名），不显示课时数，提交 `is_charge=1` + 名单存 `form_data.students`。

## 审核（Applications.jsx）

课程申报审核列表（`apps`）中，收费申报（`is_charge=1`）：
- 显示学生名单。
- 审核「通过」前，弹出一个「收费金额」输入框，教务主任填入金额后确认，随 `review` 提交 `charge_amount`。

不收费申报：维持现有逻辑（可选折算档位覆盖）。

## 计酬落库（review_application）

- 固定折算 + `is_charge=0`：现有逻辑，插 N 条 `lesson_instances`（`unit_count=1`）。
- 固定折算 + `is_charge=1`：插 1 条 `lesson_instances`，`period_type=task.period_type`（竞赛）、`manual_pay=charge_amount`、`unit_count=1`。

## 统计口径（buildFinancial）

`buildFinancial` 里，`manual_pay > 0` 的记录**不计入折算列**，而是单独归入「手工课酬」合计（金额 = manual_pay × unit_count），累加到课酬总额。财务汇总表在「按次计酬」区之后新增「手工课酬」分组（按 period_type 分组显示）。

> 待确认：财务汇总表里手工课酬的展示粒度——单独一列「竞赛收费」即可，还是需要按类型细分。

## 涉及文件

- `server/src/db.js`（4 处 ensureColumn）
- `server/src/context.js`（computePay 加 manual_pay 分支）
- `server/src/routes/applications.js`（apply 写入 is_charge；review 读 charge_amount、写 manual_pay；task 建/编辑读写 chargeable）
- `server/src/routes/stats.js`（buildFinancial 手工课酬分组）
- `client/src/pages/CourseApply.jsx`（收费开关 + 学生名单）
- `client/src/pages/Applications.jsx`（建课勾选 chargeable + 审核填金额）
