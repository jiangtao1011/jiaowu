# 常规检查情况导出报表设计

日期：2026-11-09
状态：设计定稿，待确认后实施

## 一、背景与目标

「常规检查」模块已具备：检查类型两级归类（大类 → 检查类型）、按类型的打分维度、周期标记、课表联动、照片上传，以及统计页（按教师 / 按备课组·教研组）。但目前**没有导出能力**，教务主任/教务员无法把检查情况整理成一份可归档、可汇报的文件。

目标：新增「常规检查情况导出」功能，产出一份 Excel 文件，同时满足两个场景——

1. **教务内部自用汇总**：按周期导出，看全貌、追进度，数据可再加工。
2. **向领导汇报 / 存档**：带「基本情况概述」文字总结 + 数据表，形式正式。

## 二、需求结论（头脑风暴已澄清）

| 问题 | 结论 |
| --- | --- |
| 给谁看、什么场景 | 两者都要：日常汇总 + 正式汇报 |
| 时间与组织维度 | 两种都要：按学期/类型复盘 + 按日期区间/组追踪 |
| 正式概述格式 | Excel 多 sheet（含「概述」sheet），不另出 Word |

## 三、现有数据盘点

- `inspections`：检查记录（`template_id`/`class_id`/`teacher_id`/`subject`/`lesson_date`/`cycle_label`/`data`(检查项 JSON)/`score_data`(打分快照 JSON)/`score_total`/`score_max`/`checker_id`）
- `inspection_templates`：检查类型（含 `category_id`、`cycle`、`items`）
- `inspection_categories`：检查大类
- `inspection_score_settings`：打分维度（按 `type_id`）
- `teacher_groups` + `teacher_group_members`：备课组/教研组
- 已有接口：`GET /inspections`（明细）、`GET /inspections/stats/teachers`（个人得分）、`GET /inspections/stats/groups`（组达标率/覆盖率）
- 项目已有 Excel 导出范式：`XLSX`（`xlsx` 库）多 sheet 生成，见 `stats.js` 的 `/export`、`/financial-report`

## 四、方案设计

### 4.1 后端导出接口

新增 `GET /inspections/export`，挂载在 `server/src/routes/inspections.js`。

- **权限**：收紧为「管理层 + 组长」= admin / 校长 / 教务主任 / 教务员 / 教研组长 / 备课组长 / 年级组长（即除普通教师外）。用 `RESULT_VIEW_ROLES + 教研组长 + 备课组长 + 年级组长` 判定；普通教师 403。内部仍用 `visibleTeacherIds(req.user)` 做作用域过滤（组长限本组/本学科/本年级）。
- **参数**（复用现有 `buildWhere` 的筛选语义）：
  - `from`、`to`：日期区间（可选）
  - `category_id`、`type_id`：按大类/类型过滤（可选）
  - `pass_line`：达标线（可选，默认读配置）
- **返回**：`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` 的 `.xlsx`，文件名 `常规检查情况_<from>_<to>.xlsx`。

### 4.2 Excel 结构（一个文件，5 个 sheet）

| Sheet | 内容 | 说明 |
| --- | --- | --- |
| `基本情况概述` | 文字段落 + 关键指标表 | 面向汇报，见 4.3 |
| `检查明细` | 每条记录一行 | 含各打分维度展开列 |
| `按教师汇总` | 教师一行：学科/次数/平均分/达标 | 复用 `/stats/teachers` 口径 |
| `按组汇总` | 组一行：人数/已检/平均分/达标率/覆盖率/需关注 | 复用 `/stats/groups` 口径 |
| `口径说明` | 达标线、学期起始、生成时间、生成人 | 便于审计归档 |

**检查明细 sheet 列设计**：

固定列：日期、大类、检查类型、周期标记（第 N 周）、班级、教师、学科、节次、实得分、满分、检查人。

打分维度展开列：从范围内所有记录的 `score_data` 快照中收集去重后的维度 `label`，按稳定顺序排列作为动态列头；某记录缺该维度则留空。

> 备注：维度用 `label`（中文显示名）作列头，更贴近阅读；不同检查类型维度不同时，动态列天然兼容。

**按教师汇总列**：教师、学科、检查次数、平均分（Σ实得/Σ满分×100，保留 1 位小数）、达标状态（≥ 达标线为「达标」，否则「未达标」）。

**按组汇总列**：组名、类型（备课组/教研组）、学科、年级、组长、人数、已检、平均分、达标率、覆盖率、需关注标记（覆盖率<100% 或 达标率<达标线 时为「是」）。

### 4.3 「基本情况概述」文字生成规则

概述 sheet 用多行文本自动拼装（`XLSX.utils.aoa_to_sheet`），结构如下：

```
常规检查情况报告

统计区间：{from} 至 {to}
生成时间：{YYYY-MM-DD HH:mm}
生成人：{操作人姓名}

一、基本情况
本次共开展常规检查 {total} 次，覆盖 {teacherCount} 名教师、{classCount} 个班级，
涉及 {categoryCount} 个检查大类、{typeCount} 个检查类型。
教师个人平均分为 {avg} 分，组达标率 {passRate}%，覆盖率 {coverage}%。

二、检查构成
- {大类1}：{n1} 次
- {大类2}：{n2} 次

三、需关注事项
1. 覆盖率不足的组：{组名}（{coverage}%）、…（若无则「无」）
2. 未达标教师：{姓名}（{avg}分）、…（若无则「无」）
3. 未达标组：{组名}（达标率 {passRate}%）、…（若无则「无」）

四、关键指标
（下方为关键指标表：检查次数 / 覆盖教师 / 覆盖班级 / 检查类型数 / 平均分 / 组达标率 / 覆盖率 / 达标线）
```

**统计口径**（与现有统计页一致）：
- 教师平均分 = Σ(个人 Σ实得/Σ满分×100) / 教师数
- 组达标率 = 组内「个人得分 ≥ 达标线」教师占比
- 覆盖率 = 组内已检教师占比
- 需关注事项各取前若干条（条数上限见下），超过则加「等 N 项」

**需关注判定（可配）**：
- 覆盖率关注线 `attention_coverage`（默认 100，即「覆盖率低于该值即需关注」）
- 达标率关注线复用 `pass_line`（达标率 < 该值即需关注）
- 条数上限 `attention_limit`（默认 5）

### 4.4 前端入口

在「常规检查 → 检查统计」tab 的筛选工具栏（已有 `from/to/category/type/达标线`）加一个 **「导出报表」** 按钮。

点击后用当前筛选条件构造导出 URL 并下载（带 token，`fetch` → `blob` → 触发 `a.download`，复用项目现有下载范式）。

> 时间范围：v1 直接用 from/to 日期选择器。若后续要「按学期」一键选择，可在工具栏加学期快捷下拉（把学期映射为 from/to），本次不做。
