# 技能封装设计（MCP 服务 + 技能提示词）

日期：2026-09-28

## 目标

把教务管理应用的重复工作（课表导入、课酬报表、通知拟定）封装成可供 Claude 桌面端 / Claude Code、Codex、WorkBuddy 桌面端调用的「技能」，并可持续迭代。

## 交付形态

两层：

1. **MCP 服务**（`mcp/`）——把后端 REST API 封装成标准 MCP 工具，供各桌面端 agent 通过 stdio 调用。
2. **技能提示词**（`.claude/skills/*/SKILL.md`）——定义「导入课表 / 出课酬报表 / 拟通知」的完整工作流，指导 agent 组合工具完成业务任务。

MCP 是标准协议，Claude Desktop / Claude Code / Codex / WorkBuddy 都支持，故以 MCP 为通用工具层，提示词层针对 Claude 生态写（其它平台可用同类提示词思路复用）。

## MCP 服务

- 位置：`mcp/`，Node.js ESM，依赖 `@modelcontextprotocol/sdk`（^1.30.1）。
- 传输：stdio。
- 后端地址：环境变量 `EDU_ADMIN_BASE` 可覆盖，默认 `http://localhost:4000`。
- 导出目录：`EDU_ADMIN_EXPORT_DIR` 可覆盖，默认 `~/Downloads`。
- 认证：`edu_login` 登录后 token 缓存在服务进程内，后续工具自动携带。

### 工具清单（14 个）

| 工具 | 用途 |
|------|------|
| `edu_login` | 登录换取 token |
| `edu_list_classes` / `edu_list_teachers` / `edu_list_period_types` | 查班级/教师/按次计酬类型 |
| `edu_list_schedules` / `edu_import_schedule` | 查课表 / 导课表 |
| `edu_mark_calendar` / `edu_generate_instances` | 标校历 / 生成上课记录 |
| `edu_summary` / `edu_export_payroll` | 课酬汇总 / 导出报表 |
| `edu_list_instances` | 查看按日上课记录 |
| `edu_create_notice` / `edu_publish_notice` / `edu_list_notices` | 通知 |

### 工具返回约定

每个工具返回 JSON 字符串，形如 `{"ok":true,"data":…}` 或 `{"ok":false,"error":"…"}`，与后端 API 约定一致。

## 技能提示词（Claude 生态）

`.claude/skills/` 下三个技能：

- `import-schedule`：课表导入工作流（先核对班级/教师名，再导入，处理 errors）。
- `payroll-report`：课酬报表工作流（标校历 → 生成记录 → 汇总/导出）。
- `draft-notice`：通知拟定与发布（拟文案 → 创建 → 发布 → 给分享链接）。

## 本次配套的后端改动

1. **课表导入支持按次计酬字典类型**：`schedules.js` 导入时，类型列除「正课/早自习/晚自习/答疑」外，若命中 `period_type_pays` 字典（晚读/晚练等），则保留该类型，否则回退「正课」。
2. **新增财务审核汇总表导出**：`GET /api/stats/financial-report?from_date&to_date&term`，按教师一行汇总（各类型小计 + 折算课时 + 课酬总额），带合计行与「制表人/审核人/财务复核」签字栏，导出 Excel。
3. **前端**：统计中心「教师课时汇总」卡片新增「导出财务汇总表」按钮。

## 迭代方式

技能持续迭代：改 MCP 工具增删参数 → 改对应 SKILL.md 工作流。工具是稳定接口，工作流提示词可随时优化，互不影响。
