# 工作台与移动端首页图形化重构设计

日期：2026-11-05
状态：头脑风暴定稿

## 背景

桌面端工作台（`/dashboard`）与移动端首页（`/m`）目前都是「计数卡片 + 列表」的朴素堆叠，数据不直观、缺乏图形化、视觉单调。本次在保留数据字段语义的前提下，重构信息架构并图形化。

## 核心决策

1. **力度**：视觉 + 信息架构重构。
2. **图表库**：引入 Recharts（约 100KB，与现有 React 18 兼容）。
3. **图形化三个维度**（用户选定）：
   - 待办审核构成（环形/堆叠条）
   - 检查达标率排行（横向条形）
   - 课务类型构成（环形/横向条形）
4. **桌面端工作台按角色区分**：管理工作台 vs 个人工作台。
5. **手机首页**：保持三角色视图（管理/领导看板、年级组长、教师），但重设计。
6. **不展示课酬金额**：工作台/首页图形化只展示节数、达标率、待办数等非敏感数据，课酬金额仍只留统计中心。
7. **时间范围**：工作台顶部加全局时间选择器，作用于「课务类型构成」「检查达标率排行」两个历史统计模块；待办审核是实时数据不受影响。
   - 桌面端：起止日期选择器。
   - 移动端：快捷按钮（本月 / 近7天 / 本学期）+ **自定义日期范围**（起止日期选择，选中后快捷按钮取消高亮）。

## 桌面端工作台

### 信息架构

**A. 管理工作台**（admin / 教务主任 / 教务员 / 分管领导 / 年级组长）

1. 顶部「今日快照」：日期 + 周几 + 今日课务节数 + 待办总数。
2. 全局时间范围选择器（起止日期，默认本月）。
3. KPI 指标行：班级数 / 教师数 / 本月课时 / 折算课时 / 检查记录（带图标、可点击跳转）。
4. 图形化模块：
   - 待办审核构成（环形图：课时申报 / 课程申报 / 通知回复）。
   - 课务类型构成（横向条形或环形：按 period_type 统计节数）。
   - 检查达标率排行（横向条形：各备课组/教研组 pass_rate 降序，配覆盖率）。
5. 今日课务 + 工作提醒 + 近期通知 + 教务工作日历（保留，视觉重排）。

**B. 个人工作台**（教师 / 教研组长 / 备课组长）

精简版：今日课程（时间段列表）、本周课表、我的待审申报、近期通知、工作日历。不含全校 KPI、待办审核、检查考核。

## 移动端首页

保持三角色视图，统一重设计：

### 管理/领导（数据看板）
- 顶部时间范围：快捷切换「本月 / 近7天 / 本学期」+ 自定义日期范围（起止日期选择，选中自定义后快捷按钮取消高亮）。
- KPI 网格：带图标的卡片（班级/教师/本月课时/折算课时/检查记录/待审申报）。
- 待办审核构成：横向堆叠条 + 数字（紧凑，不用环形图）。
- 课务类型构成：横向条形图。
- 检查达标率排行：横向条形，前 5 组 + 可展开。
- 近期通知、工作提醒保留。

### 教师（个人课务）
- 顶部问候 + 今日课程卡片（时间线）。
- 本周课表（星期横排，微调视觉）。
- 我的申报（状态彩色徽标）。
- 任教班级。

### 年级组长
- 待审申报数（大数字卡）+ 本月课时概览 + 未读通知。

## 视觉方案

### 设计令牌体系（CSS 变量收敛，实施时第一步重构）

现有 CSS 散落 10 多种近似灰（`#fafbfc`/`#f0f2f5`/`#f8fafc`/`#f5f7fa`/`#eef1f5`/`#f6f8fa`/`#e9edf2`/`#fbfcfd`/`#fbfdfc`/`#f4f4f4` 等），主色墨绿只有孤立一个值。层次感应由「成体系的色阶」保证，而非堆近似灰。

**A. 中性灰收敛为 5 档**：

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--bg` | `#f5f6f8` | 页面底色 |
| `--card` | `#ffffff` | 卡片 |
| `--border` | `#e6e8ec` | 分隔线/边框 |
| `--text` | `#1f2937` | 主文字 |
| `--muted` | `#6b7280` | 次要文字 |

其余近似灰统一映射到这 5 档。

**B. 主色墨绿 6 档色阶**：

| 令牌 | 色值 | 用途 |
|---|---|---|
| `--primary-050` | `#f0f7f5` | 极浅底（选中态背景） |
| `--primary-100` | `#d6ebe6` | 浅底（hover、徽标底） |
| `--primary-300` | `#7bbfb4` | 浅边框 |
| `--primary` | `#167d6f` | 主色 |
| `--primary-700` | `#0f5f54` | 深主色（hover） |
| `--primary-900` | `#0a3f38` | 最深（强调文字） |

**C. 语义色统一「浅底/主色/深色」三层规则**：danger/warn/ok/info 各按同一套明度规则生成（浅底 = 主色 10% 透明度，深色 = 主色加深 20%），保证四色视觉权重一致。

**D. 层级第三维规范**：
- 阴影 2 档：`--shadow-sm`（卡片静止）、`--shadow-lg`（悬浮/弹层）。
- 圆角 3 档：8px（输入框/按钮）、12px（卡片）、16px（弹层/大卡）。
- 卡片内边距统一 20px，卡片间距统一 16px。

### 图表与卡片

- 沿用墨绿主色，建立统一图表色板（墨绿主 + 蓝/橙/紫辅助），均从色阶体系取色。
- KPI 卡带左侧色条或图标，数字用大号等宽字体。
- Recharts 图表配色与主色协调，去除默认冗余网格线。

## 体验增强（用户采纳的建议）

1. **今日 hero 条**：今日日期 + 周几 + 今日节数 + 今日工作/校历标签做成工作台顶部视觉锚点。
2. **突出异常组**：检查达标率排行中，低于达标线的组置顶 + 红色警示，达标组折叠或淡显。
3. **图表可下钻**：
   - 待办构成的三个块分别跳转——课时申报→课务申报待审、课程申报→课程申报待审、通知回复→通知待审（各自带状态筛选）。
   - 课务类型构成的某类→统计中心并按该类型筛好。
4. **空态 / 骨架屏**：待办清空显示「待办已清空 ✓」积极反馈；图表加载用骨架屏；空数据友好提示。
5. **图表形式**：课务类型构成用**横向堆积条**（类型可能 >5 种，堆积条更易读）；待办构成用环形图（仅 3 类）。
6. **时间范围体验**：localStorage 记住上次选择；日期范围显示为可读形式（如「11月1日～11月5日」）。

## 数据接口方案

| 需求 | 方案 |
|---|---|
| 待办审核构成 | 现有 `/dashboard` 的 `todo` 字段，无需改动。 |
| 检查达标率排行 | 现有 `GET /inspections/stats/groups`（返回 `pass_rate`/`coverage`/`avg_score`），工作台取前 N 组。 |
| 课务类型构成 | **扩展 `GET /dashboard`**，新增 `lessonTypeStats`：按 `period_type` 聚合 `lesson_instances` 节数，支持 `from_date`/`to_date` 查询参数。只返回节数，不含金额。 |

## 实现顺序

1. **重构 CSS 设计令牌**（收敛近似灰、建立主色 6 阶 + 语义色三层 + 阴影/圆角/间距规范）。
2. 引入 Recharts 依赖。
3. 后端扩展 `GET /dashboard` 返回 `lessonTypeStats`（按 period_type 聚合节数，带日期参数）。
4. 新建共享组件（KPI 卡、环形图、横向条形、堆积条）。
5. 桌面端 Dashboard.jsx 重构（角色区分 + 图形化）。
6. 移动端 MobileHome.jsx 重构（三角色视图 + 图形化）。
7. 端到端验证。
