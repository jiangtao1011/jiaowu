# 角色权限岗位制重构设计

日期：2026-11-05
状态：已定稿（头脑风暴确认）

## 背景与问题

现有 7 角色：`admin` / `教务员` / `教务处` / `教研组长` / `备课组长` / `年级组长` / `教师`。

问题：
1. **「教务处」语义含糊**——既是部门名，又被当成岗位用，与「教务员」高度重叠（两者都在 `ADMIN_ROLES`）。
2. **缺少分管领导**——终审、全局查看、数据汇总全部压在 `admin` 一个人身上，无人以「领导视角」只看结果、不碰操作。
3. 权限散落：`isAdmin` 在十几个前端文件里硬编码 `['admin','教务员','教务处']`，后端 `ADMIN_ROLES` 一处改、处处漏。

## 目标

岗位制重构：把「教务处」正名为「教务主任」，新增「分管领导」纯只读角色，按五层职责重新划清权限边界。

## 岗位清单与职责定位（五层）

| 层级 | 角色 | 定位 |
|---|---|---|
| 系统层 | `admin` | 系统管理员——账号/角色管理、数据库管理、系统级配置。**不参与日常业务**（不审批、不录入）。 |
| 决策层 | `分管领导`（新增） | 校领导视角，**纯只读**。只看结果汇总（可下钻到教师明细），可导出，不碰档案、配置、审批。 |
| 管理层 | `教务主任` | 业务总负责——**终审**、业务配置（课酬系数/检查维度/考核规则/校历）、全量业务管理、账号建号（不可改角色/不动 admin）。 |
| 执行层 | `教务员` | 日常录入维护——班级/教师档案、课表导入调课、通知发布、检查提交、成绩录入。**不审批、不改配置、不建号**。 |
| 教学层 | `教研组长` / `备课组长` / `年级组长` / `教师` | 按作用域分权（已有机制，本次不变）。 |

## 关键决策记录

1. 「教务处」角色重命名为「教务主任」，现有账号自动继承（数据迁移 `UPDATE users SET role='教务主任' WHERE role='教务处'`）。
2. 分管领导纯只读：不审批、不操作；只看结果汇总 + 可下钻到教师明细 + 可导出 Excel。
3. 课务申报终审「主任专审」：`REVIEW_ROLES` 去掉教务员，改为 `['admin','教务主任','年级组长']`。
4. 教务员录入维护型：不审批、不改配置、不建号，但**可查看课酬/考核结果**（核对录入用）。
5. 建号权从「admin+教务员」改为「admin+教务主任」。
6. admin 仅系统层，日常业务不依赖它（技术兜底）。

## 技术实现方案

### 角色常量（`auth.js` / `roles.js` 单一事实源）

```js
SYSTEM_ROLES      = ['admin']                          // 数据库、角色管理独占
READONLY_ROLES    = ['分管领导']                        // 纯只读（结果汇总）
DIRECTOR_ROLES    = ['admin', '教务主任']               // 业务配置、终审
CLERK_ROLES       = ['admin', '教务主任', '教务员']      // 档案/课表/通知/成绩/检查提交
RESULT_VIEW_ROLES = ['admin', '分管领导', '教务主任', '教务员'] // 结果查看+导出
USER_EDIT_ROLES   = ['admin', '教务主任']               // 建号（不可改角色）
INSPECTION_CONFIG_ROLES = ['admin', '教务主任']         // 检查配置
INSPECTION_SUBMIT_ROLES = ['admin', '教务主任', '教务员', '教研组长', '备课组长'] // 检查提交
```

### 数据迁移（启动时幂等）

```sql
UPDATE users SET role = '教务主任' WHERE role = '教务处';
```

代码里所有 `'教务处'` 字符串替换为 `'教务主任'`。迁移幂等——已存在「教务主任」不会重复。

### 后端改造

- 写操作：按矩阵映射到 `CLERK_ROLES` / `DIRECTOR_ROLES` / `SYSTEM_ROLES`。
- 审批终审：`REVIEW_ROLES` → `['admin','教务主任','年级组长']`。
- **分管领导只读中间件** `readonlyGuard`：`分管领导` 可访问所有 GET 及导出类接口，POST/PATCH/PUT/DELETE 一律 403。保证「可下钻、可导出，但零写入」。

### 前端改造

- `roles.js` 收敛为唯一出口（`hasRole` / `canXxx`）。
- 清除十几个文件里散落的 `['admin','教务员','教务处']` 硬编码。
- `Layout.jsx` 侧边栏按角色组显隐菜单：分管领导只见「数据看板/课务统计/考核」等查看项，不见录入与配置入口。

## 影响范围

- 后端：`auth.js`、`scope.js`、`routes/*.js`（所有 `roleRequired(...ADMIN_ROLES)` 处）
- 前端：`roles.js`、`components/Layout.jsx`、`pages/*.jsx`、`mobile/*.jsx`（所有 `isAdmin` 硬编码处）
- 数据：`users.role` 一处迁移
