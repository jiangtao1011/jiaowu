# 移动端三件套：重定向修复 + 管理角色数据看板 + UI 美化

> 日期：2026-11-03 · 状态：头脑风暴定稿（待实现）

## 背景

移动端已有一套完整页面（`client/src/mobile/`，壳 `MobileShell` + 底部导航），但存在三个问题需要解决：
1. 手机浏览器访问时不能自动跳转到移动端界面（重定向失效）。
2. 管理员/教务处/教务员在手机上缺少一个「数据总览」入口，看不到核心指标、待办、检查考核情况。
3. 移动端整体 UI 较朴素，需要更美观、更便捷。

桌面端「工作台」保持不动，本次全部改动集中在移动端 + 一个后端聚合接口。

## 已确认的核心决策

1. **重定向**：全局守卫式重定向，**不加**「切桌面版」开关——手机永远进移动端，登录后自然落到 `/m`。
2. **数据看板**：专用于**手机端首页** `MobileHome`，仅 `admin`/教务员/教务处 三个管理角色看到；教师/年级组长首页保持现状。桌面端工作台不动。
3. **看板数据域**（用户勾选）：核心指标总览、待办聚合、检查与考核。
4. **检查下钻**：组级排行 → 组内教师得分一览（含「未检查」教师标灰），到此为止，不再下钻到单次检查记录。
5. **UI 美化**：在现有视觉基础上提升，不推翻重来。

## 一、手机端重定向修复

**根因**：现有 `MobileRedirect` 只挂在桌面端 `/` 的 index 路由上，且只在首次渲染判断一次——深链进入（`/stats`、`/schedules` 等）或旋转屏幕后不会跳转。

**方案**：在 `AuthGuard` 内做全局判断——登录用户 + 手机设备（`innerWidth < 768` 或手机 UA），凡访问桌面端路由一律 `Navigate` 到 `/m`；`/m` 下的路由不拦截。`/apply`、`/course/:token`、`/n/:token`、`/login` 等独立页不受影响。

## 二、手机端数据看板

### 后端：`GET /api/datacenter`（新增）

`roleRequired('admin', '教务员', '教务处')`，一次返回：

```json
{
  "overview": {
    "classes", "teachers", "users",                       // 基础
    "month_lessons", "month_weighted", "month_pay",        // 本月课时/折算/课酬（lesson_instances，未取消）
    "inspections", "pending_qna", "pending_applications", "pending_replies"  // 检查数、各待审
  },
  "todo": {
    "qna", "applications", "replies",                       // 待审数
    "overdue_uploads", "reminders"                          // 逾期上传任务、未来7天工作提醒
  },
  "inspection": {
    "pass_line": 90,
    "groups": [ { key,name,type,subject,grade,teacher_count,checked_count,coverage,avg_score,pass_rate } ],  // 组级排行
    "by_teacher": { "<groupKey>": [ {teacher_id,name,subject,count,avg_score,status} ] }  // 组内教师下钻
  }
}
```

- 复用 `groups.js` 的 `listGroups()`、`inspections` 表的 `score_total/score_max`，得分口径 = Σ实得/Σ满分×100。
- `by_teacher` 里「未检查」教师也列出（count=0、status='未检查'），这是覆盖率的核心价值——暴露谁还没被查。
- 本月区间 = 当月 1 号 ~ 今天。

### 前端：改造 `MobileHome`

管理角色（`isAdmin`）时首页渲染数据看板，替换现有「待办审核」单卡片：

1. **核心指标总览**：2×N 数字卡片网格（班级/教师/账号/本月课时/折算/课酬/检查记录/待审申报）。
2. **待办聚合**：待审课时申报、待审课程申报、待审通知回复、逾期上传任务、近期工作提醒。
3. **检查与考核**：组级排行（覆盖率/平均分/合格率，异常项标色）→ 点进组看教师得分一览。

教师/年级组长视角保持现有 `MobileHome` 逻辑不变。

## 三、手机端 UI 美化

在现有 CSS 基础上追加/微调，不动桌面端：

- **底部导航**：图标换线性 SVG，选中态加主色胶囊高亮背景；tab 触控区 ≥44px。
- **卡片**：统一圆角 14px、阴影层级、标题左侧加主色竖条点缀；数字卡片紧凑排版。
- **配色**：主色沿用墨绿 `#167d6f`（已在 `:root`），微调 `--primary-soft` 提亮；补一组看板专用色（指标卡淡色底）。
- **交互**：列表项统一触控高度；加载态用骨架屏（skeleton）替代「加载中…」文字；空状态加统一占位样式。
- **可访问性**：iOS 输入框字号 ≥16px（已满足）；对比度、间距规范。
