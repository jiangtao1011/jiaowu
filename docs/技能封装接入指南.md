# 技能封装接入指南（Claude / Codex / WorkBuddy）

本页说明如何把教务管理的 MCP 服务接到各桌面端，让 AI 助手调用「课表导入 / 课酬报表 / 通知拟定」等技能。

## 0. 前置条件

- 教务管理后端已启动（`cd server && npm start`，默认 `http://localhost:4000`）。
- MCP 依赖已安装（`cd mcp && npm install`）。

MCP 服务的启动命令（stdio 模式）：

```bash
node /Users/mac/Documents/AI工作/教务管理/mcp/src/index.js
```

可选环境变量：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `EDU_ADMIN_BASE` | `http://localhost:4000` | 后端地址（迁到学校服务器时改成内网 IP） |
| `EDU_ADMIN_EXPORT_DIR` | `~/Downloads` | 导出报表落盘目录 |

---

## 1. Claude 桌面端（Claude Desktop）

在 Claude Desktop 的配置文件里注册 MCP 服务器。

macOS 配置文件路径：`~/Library/Application Support/Claude/claude_desktop_config.json`

在 `mcpServers` 里加一项：

```json
{
  "mcpServers": {
    "edu-admin": {
      "command": "node",
      "args": ["/Users/mac/Documents/AI工作/教务管理/mcp/src/index.js"],
      "env": {
        "EDU_ADMIN_BASE": "http://localhost:4000",
        "EDU_ADMIN_EXPORT_DIR": "/Users/mac/Downloads"
      }
    }
  }
}
```

重启 Claude Desktop 后，在对话框里能看到 `edu_*` 系列工具。直接说「导入这张课表」「出这个月的课酬财务表」即可。

---

## 2. Claude Code（命令行 / IDE）

在项目根目录 `/Users/mac/Documents/AI工作/教务管理` 下，用 `.mcp.json` 注册：

```json
{
  "mcpServers": {
    "edu-admin": {
      "command": "node",
      "args": ["mcp/src/index.js"],
      "env": {
        "EDU_ADMIN_BASE": "http://localhost:4000"
      }
    }
  }
}
```

保存后用 `claude mcp add` 或重启 Claude Code 加载。项目里的 `.claude/skills/` 三个技能（import-schedule / payroll-report / draft-notice）会被 Claude Code 自动识别，可直接 `/import-schedule` 调用。

---

## 3. Codex（OpenAI）

Codex 支持 MCP。在 Codex 的配置里注册 MCP 服务器（stdio 模式），命令同上：

```bash
node /Users/mac/Documents/AI工作/教务管理/mcp/src/index.js
```

Codex 侧的具体配置方式以 Codex 官方文档为准（`codex mcp add` 或配置文件里加 `edu-admin` 项）。工具名与参数结构在各平台一致，均为 MCP 标准工具。

---

## 4. WorkBuddy 桌面端

WorkBuddy 需按 MCP 标准接入：在它的 MCP 服务器管理里添加一个 stdio 服务器，命令指向：

```bash
node /Users/mac/Documents/AI工作/教务管理/mcp/src/index.js
```

接入后即可调用同一套 `edu_*` 工具。若 WorkBuddy 没有内置「技能提示词」概念，可把 `.claude/skills/*/SKILL.md` 里的工作流描述作为提示词粘贴给它的 agent 使用。

## 常见问题

- **工具调用报「未登录」**：先让 agent 调用 `edu_login`（用户名/密码），后续工具自动带 token。
- **导出报表找不到文件**：默认存 `~/Downloads`，可用 `EDU_ADMIN_EXPORT_DIR` 改目录。
- **迁到学校服务器后连不上**：改 `EDU_ADMIN_BASE` 为服务器内网地址，如 `http://192.168.x.x:4000`。
- **课表导入有失败行**：查看工具返回的 `errors` 数组，通常是班级/教师名不一致，先补建基本信息再导。
