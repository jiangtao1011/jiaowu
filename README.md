# 教务管理应用

局域网内的 Web 应用，用于「课程中心」的教务管理事务。

## 技术栈

- 后端：Node.js 24 + Express + 原生 `node:sqlite`（零外部数据库依赖）
- 前端：React 18 + Vite
- 认证：JWT + bcrypt

## 已实现（MVP）

1. **账号与权限**：内置账号，教务员统一创建；角色 = 管理员 / 教务员 / 教务处 / 教研组长 / 备课组长 / 教师。
2. **基本信息**：班级（行政班/走班、人数）、教师（学科、课酬标准）。
3. **课表**：由 Excel/CSV 导入生成，精准到教师；早自习/晚自习一并纳入；拖拽调课、代课；课时汇总统计。
4. **通知**：可生成分享链接，发到工作群供教师免登录查看。
5. **教学计划上传**：教务员自定义上传任务（标题、人员范围、要求、截止时间），在线浏览与下载。

## 目录结构

```
server/   后端（Express + node:sqlite，同时托管前端静态文件）
client/   前端（React + Vite，build 产物由后端 4000 端口托管）
docs/     设计文档
start.sh  一键启动脚本
```

## 启动方式

前端已由后端统一托管在 **4000 端口**，只需启动一个进程。

### 一键启动

```bash
./start.sh           # 直接启动（用已有前端构建产物）
./start.sh build     # 先重新构建前端再启动（改了 client/ 代码后用这个）
```

### 手动启动

```bash
# 1. 后端（含前端静态托管）
cd server
npm install
npm run seed       # 首次运行，创建初始管理员账号
npm start          # 默认 http://localhost:4000

# 2. 前端（仅开发调试用；对外访问无需单独启动）
cd client
npm install
npm run build      # 构建产物到 client/dist，供后端托管
npm run dev        # 可选：开发热更新，http://localhost:5173
```

## 固定访问地址

服务通过 **mDNS 主机名** 提供稳定访问地址，**局域网 IP 变化不影响**：

```
http://jiaowu.local:4000
```

- 首次使用需先改一次主机名（终端运行）：`sudo scutil --set LocalHostName jiaowu`
- Mac / iPhone / iPad 开箱即用
- Windows 需安装 Apple Bonjour 才能解析 `.local`
- 若局域网做了客户端隔离（AP isolation）导致 mDNS 不通，改用「DHCP 静态绑定」：
  在路由器（网关 172.16.31.254 / DHCP 172.16.0.1）按本机 MAC `72:a0:dd:e6:17:8b` 固定分配 IP，之后用 `http://<固定IP>:4000` 访问。

> ⚠️ 改了 `client/` 下的前端代码后，需重新 `npm run build`（或 `./start.sh build`）才会生效；后端是启动时读取静态文件。

## 课表导入格式

支持 `.xlsx` / `.xls` / `.csv`。表头需包含以下列（中文优先）：

| 班级 | 星期 | 节次 | 类型 | 时段 | 科目 | 教师 |
|------|------|------|------|------|------|------|
| 高一(1)班 | 1 | 1 | 正课 | 常规 | 数学 | 张三 |

- 星期：1–7（1=周一）
- 类型：`正课` / `早自习` / `晚自习` / `答疑`
- 时段：`常规` / `夏令营` / `冬令营` / `全员夏令营` / `全员冬令营` / `节假补课`（缺省为「常规」）
- 导入前需先在「班级信息」「教师信息」中建立对应数据，否则该行会提示未导入

## 批量导入与模板

班级、教师、课表均支持批量导入（Excel/CSV），各页面提供「下载导入模板」按钮。课表导入支持格式容错（班级/教师/科目/时段等列名兼容多种写法），方便与后续技能配合做格式转化。

## 统计中心

「统计中心」页面集中了课时汇总与调课记录，支持两种口径：

- **当前状态**：统计当前生效的课表条目数
- **按时间段**：选择起止日期，系统按课表每周重复自动折算该区间内实际课时数

两者均支持按「时段」（常规/夏冬令营等）筛选。调课/代课/停课采用历史快照模式，变化前的统计不受影响。
