# 课酬统计报表

生成课酬统计报表，供上交给财务审核、归档、打款。报表基于「按日统计」口径，能精确表达临时变动、补课、放假、不定期答疑。

## 统计口径说明

课酬按「按日」精确统计，流程是：

1. **标记校历**：把放假、补课、停课的特殊日期标出来（`edu_mark_calendar`）。
2. **生成上课记录**：把固定课表按校历展开成按日的上课记录（`edu_generate_instances`）。
3. **汇总/导出**：按教师汇总课酬（`edu_summary`），或导出 Excel（`edu_export_payroll`）。

## 执行步骤

1. 先调用 `edu_summary`（需要 `from_date`、`to_date`），得到每位教师的课时与课酬，向用户展示核对。
2. 若用户说「出财务要的表」，调用 `edu_export_payroll`：
   - `kind=financial` → 财务审核汇总表（按教师一行，含各类别小计、折算课时、课酬总额、签字确认栏），**这是交给财务的**。
   - `kind=detail` → 明细表（每节课一行，含日期/班级/教师/折算课时/课酬），用于内部核对。
3. 返回导出文件的保存路径给用户。

## 关键概念（向用户解释时要准确）

- **原始课时**：实际上的课节数。
- **折算课时**：正课 = 节数 ×（课时系数 + 班额系数）；早自习 = 节数 × 早自习系数；夏/冬令营 = 节数。
- **课酬（元）**：按次计酬类型（晚自习/答疑/晚读/晚练）= 固定单价 × 节数；夏/冬令营 = 节数 × 教师课酬标准。
- **走班班额** = 合班各行政班人数之和（影响班额系数）。

## 常见问题

- 统计结果为空：通常是区间内还没「生成上课记录」。先 `edu_generate_instances`。
- 日期区间默认当月 1 号到今日，用户可按需指定（如整月、整学期）。
- 若要按某个时段单独看（如只算夏令营），传 `term` 参数。
- 财务汇总表里没有签字栏外的说明时，可在 Excel 里补；导出本身已带「制表人/审核人/财务复核」栏。
