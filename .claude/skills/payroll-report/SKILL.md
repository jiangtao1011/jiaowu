# 课酬统计报表

生成课酬统计报表，供上交给财务审核、归档、打款。报表基于「按日统计」口径，能精确表达临时变动、补课、放假、不定期答疑。

## 统计口径说明（向用户解释时要准确）

课酬（钱）只来自两类：

- **按次计酬类型**（晚自习/答疑/晚练/自定义）：课酬 = 固定单价 × 节数。
- **非规时段**（夏令营/冬令营/全员夏令营/全员冬令营/节假补课）：课酬 = 节数 × 教师课酬标准（pay_standard 对应时段档）。

**不计钱**（只出折算课时，供教学业绩考核）：常规正课（折算 = 节数 ×（学科系数+班额系数））、早自习（折算 = 节数 × 早自习系数）。

## 财务对账工作流（务必按序执行）

1. **标记校历**：放假/补课/停课/调课标出来（`edu_mark_calendar`）。
2. **生成上课记录**：把固定课表按校历展开成按日记录（`edu_generate_instances`，replace 默认 true）。
3. **勾稽校验**：调 `edu_financial_check`，检查「明细金额 = 汇总金额」是否一致，并读异常清单。
   - 若有异常（无价类型 / 缺课酬标准 / 代课计数异常 / 单人偏高），先向用户说明，等确认修正后再继续。
   - 若勾稽不一致或异常未清，**不要直接出包**。
4. **导出财务审核包**：确认无异常后，调 `edu_export_financial_pack`（单文件四 sheet：财务汇总表 + 课酬明细 + 勾稽校验 + 口径说明）。若用户只要其中一张，可用 `edu_export_payroll`（kind=detail / kind=financial）。
5. **固化**：财务审核通过后调 `edu_archive_payroll` 固化快照，防止后续改课表/重新生成影响已归档月份。
6. **汇报**：向用户报告对账结果、异常处置、导出文件路径、是否已固化。

## 关键概念（解释要准确）

- **原始课时**：实际上的课节数。
- **折算课时**：正课 = 节数 ×（课时系数 + 班额系数）；早自习 = 节数 × 早自习系数；夏/冬令营 = 节数。
- **课酬（元）**：按次计酬类型 = 单价 × 节数；非规时段 = 节数 × 教师课酬标准。
- **走班班额** = 合班各行政班人数之和（影响班额系数，进而影响正课折算课时，但不影响课酬金额）。

## 常见问题

- 统计结果为空：通常是区间内还没「生成上课记录」。先 `edu_generate_instances`。
- 日期区间默认当月 1 号到今日，用户可按需指定（如整月、整学期）。
- 若要按某个时段单独看（如只算夏令营），传 `term` 参数。
- 勾稽校验提示「无价类型」：某 period_type 不在按次计酬字典，被当正课处理（不计钱）。若应计酬，需在「统计配置」添加该类型。
- 勾稽校验提示「缺课酬标准」：某教师在非规时段缺 pay_standard 档，需在「教师信息」补该时段标准。
