# 通知拟定与发布

拟定通知文案，创建到系统里，生成免登录链接发到工作群。

## 通知类型

- **课务调整通知**：调课、代课、停课、补课等课务变动。
- **考试通知**：考试时间、科目、考场安排、监考要求。
- **其他**：自定义内容。

## 执行步骤

1. **拟定文案**：根据用户意图写通知正文。课务调整通知要写清——变动日期、节次、班级、原安排、新安排、涉及教师；考试通知要写清——考试时间、科目、考场、要求。
2. 调用 `edu_create_notice`，传入 `title`、`type`、`content`，得到通知 ID 与 `share_token`。
3. 调用 `edu_publish_notice`（传入通知 ID）把它发布。
4. 生成分享链接，格式为 `http://<本机IP或域名>:5173/notice/<share_token>`，把链接给用户发到工作群。

## 文案要点

- 通知要**信息完整、无歧义**：时间（年月日 + 节次）、地点/班级、人物（教师/学生）、事项。
- 语气正式、简洁，符合学校公文习惯。
- 涉及多名教师时逐条列出，不要挤成一段。
- 需要附件时提醒用户，附件要单独在系统里上传（本技能只处理正文）。

## 注意事项

- `share_token` 是免登录访问凭证，只给工作群内部使用，不要发到公开网络。
- 通知先存草稿、确认无误后再发布；发错可让用户删除后重发。
