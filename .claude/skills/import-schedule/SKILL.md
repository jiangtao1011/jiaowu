# 课表导入

把学校提供的课表文件导入教务管理系统。课表需精准到每一位老师，含早自习、晚自习、晚读等类型。

## 前置准备（必须先做）

导入前，系统里必须已存在对应的班级和教师，否则对应行会导入失败。

1. 调用 `edu_list_classes` 拿到所有班级名称。
2. 调用 `edu_list_teachers` 拿到所有教师姓名。
3. 调用 `edu_list_period_types` 拿到按次计酬类型名（晚自习/答疑/晚读/晚练等自定义类型）。
4. 若用户的课表文件里出现了系统里没有的班级名或教师名，**先提醒用户**，不要硬导。

## 课表文件规范

表头需包含（中文优先，系统做了容错，这些别名都认）：

| 列 | 说明 |
|----|------|
| 班级 | 必须与系统班级名完全一致（含空格/符号） |
| 星期 | 1=周一 … 7=周日 |
| 节次 | 第几节课（数字） |
| 类型 | 正课 / 早自习 / 晚自习 / 答疑，或按次计酬字典里的类型名（如 晚读、晚练） |
| 时段 | 常规 / 夏令营 / 冬令营 / 全员夏令营 / 全员冬令营 / 节假补课（缺省常规） |
| 课程名称 | 语文、数学等 |
| 教师 | 必须与系统教师姓名完全一致 |

> 系统根据「班级名称」自动识别上课形式（行政班/分层/走班/走班分层），无需额外填。

## 执行步骤

1. 确认文件路径（用户拖入的本地文件，取绝对路径）。
2. 调用 `edu_import_schedule`，传入 `filePath`。
3. 若是一次整体换表（新学期换课表），传 `effective_from` 为生效日期、`scope` 为 `all`（或 `grade`/`term` 限定范围）；若只是追加新课，不传 scope。
4. 检查返回的 `errors` 数组——里面是「班级/教师不存在」等未导入的行。若有，把失败行读出来，帮用户定位并修数据。
5. 汇报结果：成功导入多少条、哪些行失败、原因是什么。

## 注意事项

- 导入是「写入」操作，务必先核对班级/教师名称，不要凭空猜。
- `scope=all/grade/term` 会**关闭旧课表**（把 effective_to 设为生效日），历史统计不受影响。除非用户明确要换表，否则用默认的 append。
- 早自习、晚自习、晚读都要一起导入，不要遗漏。晚读若不在字典里，需先在统计配置中加该类型再导入。
